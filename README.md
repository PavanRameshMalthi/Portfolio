A modern, responsive, and performance-optimized portfolio website showcasing my projects, skills, and experience as a Full Stack Developer. Built with a sleek dark theme, interactive terminal hero section, and smooth scroll animations.

• Responsive Design
• Modern UI


## Deployment

This portfolio is statically optimized and can be instantly deployed on **GitHub Pages**, **Vercel**, or **Netlify** by simply connecting the repository and setting the root directory as the deployment target.

## Customization

To update the portfolio content:

• **Personal information**: Edit the text directly in the `<section id="about">` and `<section id="hero">` inside `index.html`.
• **Projects**: Modify the project cards inside the `#projects` section in `index.html`.
• **Skills**: Update the SVG icons and text inside the `.skill-card` elements in the `#skills` section.
• **Terminal Content**: Edit the `terminalContent` array in `js/script.js` to change the interactive typing animation.
• **Contact links & Social media**: Update the `href` attributes in the `#contact` section.
